## 9. Кезең 8 — Browser E2E

`tests/e2e.test.mjs` (Playwright) дайын, бірақ **бұл sandbox-та іске қосылмады**:
Chromium іске қосылу үшін қажет `libnspr4.so`, `libatk-1.0`, `libatk-bridge-2.0`, `libXdamage`,
`libxkbcommon`, `libasound`, `libatspi` жүйелік кітапханалары жоқ, ал `apt-get` root құқығын
талап етеді. Скрипт `npx playwright install --with-deps chromium` орындалған ортада жұмыс істейді:

```bash
npx playwright install --with-deps chromium
node tests/run-tests.mjs          # E2E кезеңі қосылады
```

**Бұл шектеуді жасырмаймыз:** браузер деңгейіндегі визуалды E2E тексерісі осы ортада
орындалмаған. Оның орнына jsdom-да нақты React компоненттері mount етіліп, интерактивті түрде
тексерілді (жоғарыдағы 4-кезең).
