# Тарихи мазмұн / Historical content model

## 1. Қағидаттар

1. **Бір факт — бір тұжырым.** `shared/facts.ts` ішіндегі әр жазба бір ғана
   субъект–атрибут–мән үштігін білдіреді. Сұрақтар осы фактілерден генерацияланады, сондықтан
   екі түрлі тұжырым бір сұрақта араласып кетуі мүмкін емес.
2. **Дистракторлар — нақты фактілер.** Дұрыс емес нұсқалар сол атрибуттың *басқа нақты*
   мәндерінен алынады. Ойдан шығарылған мәтін пайдаланылмайды.
3. **Дереккөзсіз факт жоқ.** Әр факт `src: string[]` өрісінде дереккөз id-лерін көрсетеді
   (`shared/sources.ts`). Тест `all facts reference known sources` мұны тексереді.
4. **Даулы мәселе ашық жазылады.** `note` өрісі түсіндірмеге қосылады, `disputed: true` белгісі
   интерфейсте «даулы» деп көрсетіледі.
5. **Ойын ойдан шығарылғанын жасырмайды.** `shared/decisions.ts` карталары «Бұл — ойын шешімі»
   деп таңбаланады, жанында `history` өрісінде дереккөзге сүйенген нақты контекст беріледі.
6. **Бейнелер — иллюстрация.** Портреттер мен жәдігерлер SVG-де қолмен салынған, «стильденген
   бейне / стильденген сурет» деп таңбаланады. Ешбір сурет тарихи фотосурет деп мәлімделмейді.

## 3. Сұрақ генерациясы

`shared/question-gen.ts` — детерминді генератор:

- Seed = FNV-1a хеші (сұрақ id-і бойынша) → xorshift32 PRNG. Бір id әрдайым бір сұрақ береді,
  сондықтан нәтижені кейін қайта тексеруге болады және сұрақты «қайта жүктеу» арқылы өзгерту
  мүмкін емес.
- Форматтар: `mcq` (тура/кері), `truefalse` (дұрыс/қате нұсқалары), `fill-blank` (чип таңдау —
  еркін мәтін енгізуден гөрі әділ бағалау), `map` (координатасы бар `place` фактілері),
  `image-id` (жәдігер каталогы), `match-dates` / `match-persons` (4 жұп), `chronological`
  (4 нақты мерзімді оқиға), `find-mistake` (3 дұрыс + 1 әдейі ауыстырылған), `multi-select`
  (3 дұрыс + 2 қате).
- `publicQuestion()` сервер жағында `key` өрісін алып тастайды — жауап кілті клиентке түспейді.
- `checkAnswer()` — жалғыз авторитетті тексеруші (серверде).
- `validateBank()` — тест қолданатын құрылымдық тексеруші (бос кілт, диапазоннан тыс индекс,
  жетіспейтін түсіндірме/дереккөз, қайталанатын id).

## 4. Мазмұнды қалай өзгерту керек

**Факт қосу:** `shared/facts.ts` ішіне жазба қосыңыз (`id` бірегей, `src` толтырылған,
`attr` дұрыс таңдалған). Сұрақтар автоматты түрде генерацияланады.
Содан кейін: `npm test` (банк валидаторы қатені бірден көрсетеді).

**Тұлға қосу:** `shared/persons.ts` — `portrait.kind` (man/woman/rider/scholar/ruler) және
палитра; `relatedLevels` — `gameId-level` форматында.

**Оқиға қосу:** `shared/events.ts` — `year` (б.з.д. теріс сан), `yearLabel` (адам оқитын түрі),
`disputed` қажет болса.

**Ойын деңгейін өзгерту:** `shared/games.ts` — `levelKey` тұрақты болуы керек (прогресс соған
байланысты).

**Дереккөз қосу:** `shared/sources.ts` — `kind` (`institutional` / `academic` / `primary` /
`encyclopedia` / `museum`) дұрыс таңдалуы маңызды, өйткені ол интерфейсте көрсетіледі.

**Әкімші арқылы сұрақ қосу:** `/admin` → «Сұрақтар» → «Жаңа сұрақ қосу». Тек `mcq`/`truefalse`/
`fill-blank` форматтары қолдау көрсетіледі; түсіндірме міндетті (кемінде 10 таңба).
