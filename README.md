# ҚАЗАҚСТАН ТАРИХЫ | HISTORY GAME ARENA

**Қазақстан тарихы бойынша интерактивті ойын-білім платформасы**
Interactive gaming & education platform on the history of Kazakhstan.

Алты түрлі жанрдағы ойын · 60 ойналымды деңгей · 1 616 верификацияланған сұрақ · 14 тарихи дәуір ·
интерактивті карта · уақыт шкаласы · 31 тарихи тұлға · оқушы/оқытушы/әкімші кабинеттері.

Интерфейс тілі — **қазақ тілі** (100%). Техникалық құжаттама және код түсініктемелері — ағылшын тілінде.

## 1. Жылдам бастау (Quick start)

```bash
npm install          # тәуелділіктерді орнату (better-sqlite3 native build қажет)
npm run dev          # http://localhost:8787  (API + жиналған клиент)
npm test             # 112 автоматты тест (content + API + render + game engine)
```

Өндіріс режимі:

```bash
npm run build        # React клиентін dist/ ішіне жинау
npm start            # NODE_ENV=production, dist/ статикасын береді
```

Бірінші іске қосылуда дерекқор (`data/arena.db`) автоматты түрде құрылады және демо аккаунттар
жасалады (`SEED_ON_BOOT=off` арқылы өшіруге болады).

### Демо аккаунттар

| Рөл | E-mail | Құпия сөз |
|---|---|---|
| Оқушы | `student@arena.kz` | `Student12345!` |
| Оқытушы | `teacher@arena.kz` | `Teacher12345!` |

## 3. Технологиялық стек

| Қабат | Технология | Ескерту |
|---|---|---|
| Frontend | React 19 + TypeScript + Vite | SPA, lazy-free, 1.1 MB JS (295 KB gzip) |
| Стиль | Tailwind CSS 4 (`@theme` tokens) + custom CSS | glassmorphism, Lora + Inter қаріптері |
| 3D | Three.js (raw, ортақ renderer жоқ) | 2 ойында: adventure, race |
| 2D | Canvas 2D (өз қозғалтқыштары) | defense, puzzle, backdrop |
| Backend | Node.js 20 + Express 5 | REST API, 40+ эндпоинт |
| Дерекқор | SQLite (`better-sqlite3`, WAL) | Firestore-ға 1:1 миграцияға дайын схема |
| Аутентификация | E-mail + scrypt пароль (үшінші тарап жоқ) | cookie (httpOnly) + Bearer token |
| Тест | Node test runner + jsdom + Playwright (script) | 211 автоматты тексеріс |

### Неге SQLite, Firebase емес?
Тапсырмада «Firebase **немесе сол деңгейдегі сенімді backend**» деп көрсетілген. Бұл нұсқада
**нақты жұмыс істейтін, тексерілген** backend таңдалды: Firebase/Firestore эмуляторынсыз нақты
жобаны тексеру мүмкін емес еді, ал «жалған» Firebase конфигурациясы талапқа қайшы. Схема
Firestore коллекцияларымен 1:1 сәйкес келеді — [docs/DATABASE.md](docs/DATABASE.md) ішінде
миграция жолы көрсетілген.

## 5. Қауіпсіздік

- **Пароль:** `scrypt` (N=16384, r=8, p=1, 64-байт) + әр қолданушыға 32-байт кездейсоқ тұз.
  Ашық мәтін ешқашан сақталмайды немесе логқа жазылмайды.
- **Сессия:** 32-байт кездейсоқ токен; дерекқорда тек **SHA-256 хеші**. Браузерде `HttpOnly`,
  `SameSite=Lax` cookie (HTTPS-те `Secure`) + SPA үшін Bearer тақырыбы.
- **Үшінші тарап кіру жоқ.** Google OAuth мүлдем алынып тасталды (талап бойынша): `/api/auth/google/*`
  маршруттары жойылған (404), `/api/auth/providers` тек `password` қайтарады. Конфигурациялайтын
  сыртқы кілт жоқ.
- **Онлайн мультиплеер:** токен бірінші WebSocket фреймінде жіберіледі (URL-ге түспейді, логқа
  жазбайды); әр кадр үшін rate limit; жауап тек серверде тексеріледі; уақыт сервер сағатымен
  өлшенеді; бір сұраққа бір жауап; жауап кілті сокет арқылы ешқашан жіберілмейді.
- **Ұпай валидациясы:** барлық сұрақ таңдауы мен тексеру серверде. Клиент «baseScore» мәні
  `questions × 120` шегіне дейін ғана қабылданады және 50%-бен салмақталады; бір сессияны екі рет
  аяқтау мүмкін емес (idempotent). Жауап кілттері жауап ретінде ешқашан жіберілмейді.
- **RBAC:** `student` / `teacher` / `admin`. Оқушы мен оқытушының әкімшілік API-ға рұқсаты жоқ —
  тестілерде тексерілген. Бас тартулар `security_log` кестесіне жазылады.
- **Rate limiting:** тіркелу 10/мин, кіру 20/мин, жауап беру 200/мин, сессия бастау 40/мин.
- **Тақырыптар:** CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`.
  (`X-Frame-Options` әдейі қойылмаған — қолданба sandbox preview ішінде көрсетілуі керек.)

## 6. Тарихи дәлдік

- Барлық фактілер **12 дереккөзге** сілтенеді (`shared/sources.ts`): E-history.kz, Қазақстан Ұлттық
  энциклопедиясы, академиялық монографиялар, мұражай қорлары, мұрағат құжаттары, бастапқы жазба
  деректер (Орхон жазбалары, «Тарих-и Рашиди», «Жамиғ ат-тауарих»), Конституция.
- Әр жауаптан кейін **түсіндірме + дереккөз id-лері** көрсетіледі.
- **Даулы мәселелер** ерекше белгіленеді (`note`, `disputed`): Қазақ хандығының құрылған жылы,
  «Жеті Жарғының» мәтіні, Ботай жылқысы, Ақ Орда/Көк Орда атаулары, сақ мемлекеттілігінің деңгейі т.б.
- **Ойдан шығарылған дүниелер ажыратылады:** стратегия шешім карталары «Бұл — ойын шешімі» деп
  таңбаланады және жанында нақты тарихи контекст беріледі; ойын брифингтері тарихи оқиға ретінде
  ұсынылмайды.
- **Бейнелер:** барлық портреттер мен жәдігерлер — **стильденген SVG иллюстрациялар** (тарихи
  фотосурет емес), бұл әр жерде жазылған.
- **Карта:** шекаралар **стильденген схема** (үзік сызық = stylised). Бұл туралы карта бетінде
  нақты ескерту бар.

## 7. Онлайн мультиплеер (WebSocket)

«Тарих майданы» ойынында нақты уақыттағы онлайн сайыс бар.

| Мүмкіндік | Мәлімет |
|---|---|
| Транспорт | WebSocket, сол HTTP серверде `/ws` жолы (қосымша порт/сервис жоқ) |
| Ойыншы | 2–8 адам, бөлме коды (6 таңба) немесе шақыру сілтемесі `?room=КОД` |
| Режим | жеке жарыс және командалық 2×2 |
| Уақыт | әр сұраққа 5–45 сек (қонақжай таңдайды), **сервер сағатымен** өлшенеді |
| Ұпай | тек серверде: `100 + серия×20 + жылдамдық бонусы`; клиент ұпай жібере алмайды |
| Бот | қонақжай 1 немесе 3 бот қоса алады (жеке сынау үшін) |
| Сақтау | әр адамның нәтижесі `game_sessions` + `student_results` кестесіне түседі, XP мен жетістіктер есептеледі |
| Қайта қосылу | сол аккаунтпен қайта қосылса, орын мен жиналған ұпай сақталады |

Серверге қосылу: `wss://<домен>/ws`. Reverse proxy артында `Upgrade` тақырыбын жіберуді ұмытпаңыз
(`.env.example` ішінде nginx үлгісі бар).

## 7.1. Қаріптер (қазақ типографикасы)

Барлық мәтін **Lora** қаріпімен беріледі және қаріп **өз серверімізден** жүктеледі
(`public/fonts/`, SIL Open Font License 1.1):

- `lora-normal-cyrillic.woff2` — `U+0400-045F` (і, ұ қамтиды)
- `lora-normal-cyrillic-ext.woff2` — `U+0460-052F` (**ә ғ қ ң ө ұ ү һ**)
- латын және latin-ext нұсқалары (сандар, тыныс белгілері, «» —)

Барлық 9 қазақ әрпінің (Ә Ғ Қ Ң Ө Ұ Ү Һ І — үлкен-кіші 18 таңба) болуы шрифт файлдарын
нақты Brotli-мен ашып тексеретін тестпен расталады (`fonts: all 18 Kazakh letters exist…`).
Google Fonts-қа ешбір сұраныс жіберілмейді — CSP `font-src 'self'` және қолданба офлайн да
дұрыс көрінеді.

> `render.yaml` арқылы Render.com-ға бір басумен шығару (тұрақты домен, тегін жоспар),
> немесе `docker build -t history-arena . && docker run -p 8787:8787 -v arena-data:/data history-arena`.


Бұл бөлім «жасалмаған нәрсені жасалды деп көрсетпеу» қағидасы бойынша жазылған.

1. **Онлайн мультиплеер бір сервер процесінде жұмыс істейді.** Бөлмелер жадыда сақталады
   (`server/multiplayer.js`), сондықтан бірнеше инстанция (horizontal scaling) қажет болса, ортақ
   күйді Redis-ке шығару немесе sticky-session қосу керек. Бұл шектеу нақты: 100+ бір уақыттағы
   ойыншыға дейін бір процесс жетеді, одан кейін масштабтау қажет.
2. **Онлайн режимде сұрақ саны 5–20** (әдепкі 10). Сессияда қайталанбайды, бірақ әр деңгейдің
   тақырыптық таңдауы ортақ пулдан алынады — жергілікті режимдегідей деңгейге қатаң байланыспаған.
3. **Браузер деңгейіндегі E2E Playwright скрипті осы ортада іске қосылмады** — sandbox-та Chromium
   үшін жүйелік кітапханалар жоқ (root құқығы жоқ). Орнына jsdom-да нақты React компоненттері
   mount етіліп, барлық 10 сұрақ форматы мен 6 ойын қабығы интерактивті түрде тексерілді.
   Скрипт (`tests/e2e.test.mjs`) дайын — `npx playwright install chromium` кейін жұмыс істейді.
4. **3D көріністер стильденген.** Three.js әлемдері процедурлық геометриядан жасалған (дала, киіз
   үй силуэттері, ат, қақпа) — AAA-деңгейдегі модельдер/текстуралар жоқ (олар үшін 3D-контент
   құбыры мен лицензияланған ассеттер қажет). Барлық көріністер нақты уақытта WebGL-де
   рендерленеді.
5. **Тек бір қаріп отбасы (Lora).** Талап бойынша барлық мәтін Lora-мен беріледі. Lora — serif
   қаріп, сондықтан өте ұсақ (10–11px) сандық кестелерде оқылымдылық sans-serif-ке қарағанда
   төмендеу; қаріп толығымен өз серверімізден жүктеледі (Google Fonts-қа сұраныс жоқ).
6. **Админ мазмұн редакторы шектеулі:** әкімші тек `mcq`/`truefalse`/`fill-blank` форматтарында жаңа
   сұрақ қоса алады; күрделі форматтар (match, chronological, map) детерминді генератордан
   келеді. Себебі: бұл форматтардың жауап кілтін қолмен енгізу қатеге өте бейім.
7. **Firebase Hosting/Cloud Run-ға автоматты deploy жасалмаған** — deployment нұсқаулығы дайын
   ([docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)), бірақ нақты жобаға шығару үшін сіздің
   аккаунт/секреттер қажет.
8. **Апталық сынақ** тек метадеректерді қайтарады (`/api/challenges/weekly`), толық ойын ағыны
   күнделікті сынақ арқылы жүзеге асады.
